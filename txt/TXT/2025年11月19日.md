## 写一个python【快速创建git分支】的脚本
* 具体需求如下
* 1、可视化操作
* 2、自动获取本地git工具，获取不到则要求手动选择
* 3、选取需要新建分支的项目目录
* 4、选择基于哪个分支拉取新分支，比如“3.1.4”
* 5、输入新分支名字，比如“南京胸腔医院”，需要先查一下有没有这个医院的分支，或者类似分支，比如“3.1.0-南京胸腔医院”，有的话则提示。新建分支名称需要拼接老分支的分支名称，比如选择了“3.1.4”，新建的分支名称就是“3.1.4_南京胸腔医院”。
* 6、点击推送按钮，推送到远端
*  配置文件引入方式如下：
    * 绝对路径引入配置文件的代码，确保无论脚本在何处执行，都能准确定位到配置文件
    * 通用数据库配置：DB_CONFIG_PATH，都是在运行脚本的父级目录的json文件夹，里面的DB_CONFIG.json
*  可视化操作给我加上合适的操作按钮
*  记录操作日志“PROCESS_LOG_FILE”的log文件里面


### 配置实例
```python
# 配置与常量
import os
from pathlib import Path

SCRIPT_DIR = Path(os.path.abspath(os.path.dirname(__file__)))
SCRIPT_NAME = "chinese_translator"
CONFIG_DIR = SCRIPT_DIR / "json"
CONFIG_PATH = CONFIG_DIR / f"config_{SCRIPT_NAME}.json"
CONFIG_DIR.mkdir(exist_ok=True)
DB_CONFIG_PATH = (SCRIPT_DIR.parent) / "json" / "DB_CONFIG.json"
PROCESS_LOG_FILE = SCRIPT_DIR / "json" / "logs" / f"log_{SCRIPT_NAME}.log"
```
