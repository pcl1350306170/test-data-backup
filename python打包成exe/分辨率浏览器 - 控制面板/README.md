# 🖥️ 分辨率浏览器 - 控制面板

> 一个轻量级的 Web 页面分辨率模拟工具，支持自定义宽度、高度、URL，并可设置无边框、可调整大小等显示模式，适用于前端开发调试。

---

## 🧩 功能简介

本工具是一个基于 Python + Tkinter 的桌面应用，允许你在本地快速打开一个指定尺寸和 URL 的浏览器窗口，模拟不同设备的显示效果。特别适合：

- 响应式网页测试
- 移动端 UI 调试
- 设计稿对齐验证
- 内部系统预览（如医院 H5 页面）

## 🚀 使用方法

* 下载“分辨率浏览器 - 控制面板.7z.001”==》“分辨率浏览器 - 控制面板.7z.005”所有文件，使用压缩工具解压

### 第一步：配置参数

| 字段 | 说明 |
|------|------|
| **宽度 (px)** | 设置浏览器窗口的宽度，例如：2880（4K）、1920（全屏）、375（手机） |
| **高度 (px)** | 设置浏览器窗口的高度，例如：320（手机）、1080（PC） |
| **URL** | 输入你要加载的网页地址，支持本地服务（如 `http://localhost:3000`）或外部链接 |

### 第二步：选择显示模式

| 选项 | 说明 |
|------|------|
| ✅ **无边框** | 启用后，窗口将去除标题栏和边框，实现“沉浸式”浏览 |
| ☐ **可调整大小** | 启用后，用户可以拖拽窗口改变大小（仅在有边框时有效） |
| ✅ **可拖动（仅无边框时有效）** | 启用后，在无边框模式下可以通过点击窗口任意位置拖动窗口 |

> ✅ 默认推荐：勾选「无边框」+「可拖动」，用于模拟真实设备体验。

---

### 第三步：操作按钮

| 按钮 | 功能 |
|------|------|
| 🔄 **应用并刷新** | 应用当前配置，关闭控制面板，启动浏览器窗口 |
| 💾 **保存配置** | 将当前设置保存到 `config.json`，下次启动自动加载 |
| ⏹ **退出** | 关闭程序 |

---

## 📂 示例配置

```json
{
  "width": 2880,
  "height": 320,
  "url": "http://localhost:3000",
  "borderless": true,
  "resizable": false,
  "draggable": true
}
```

> ✅ 这个配置常用于测试医院 H5 页面在大屏终端上的显示效果。

## ⚠️ 注意事项

1. **必须开启本地服务**
    - 确保你已启动目标网站（如 Vue/React 项目），且 `http://localhost:3000` 可访问
    - 若无法打开，请检查端口是否被占用或防火墙设置

2. **无边框模式下的拖动**
    - 无边框时窗口没有标题栏，需启用「可拖动」功能才能移动窗口
    - 拖动方式：点击窗口任意区域即可拖动

3. **配置文件自动保存**
    - 每次点击「保存配置」都会更新 `config.json`
    - 下次启动时自动读取上次配置

4. **不支持 HTTPS 自签名证书**
    - 如果你的网站使用了自签名 SSL 证书，可能会出现安全警告或无法加载

5. **Windows 系统兼容性**
    - 推荐以管理员身份运行（避免权限不足）
    - 不要在中文路径下运行程序

## 🛠️ 技术栈

- **语言**：Python
- **GUI 框架**：Tkinter
- **打包工具**：PyInstaller
- **核心逻辑**：
    - 使用 `webbrowser` 模块打开浏览器

    - 支持配置持久化（JSON）
