
# 📱 ADB 设备管理器 - QtScrcpy 集成版

> 一个轻量级、图形化的 Android 设备投屏与管理工具，集成 QtScrcpy 投屏程序，支持一键连接、启动投屏、清空设备及查看日志。

---

## 🧩 功能简介

本工具基于 QtScrcpy（开源投屏软件）封装而成，提供以下功能：

- ✅ 设置 ADB 工具路径
- ✅ 指定 QtScrcpy 投屏程序路径
- ✅ 输入并保存设备 IP 地址
- ✅ 一键连接设备
- ✅ 启动投屏（自动调用 QtScrcpy）
- ✅ 清空设备数据（模拟重置）
- ✅ 查看最近操作日志

适用于开发者、测试人员或需要频繁调试 Android 设备的用户。

## 🚀 使用方法

### 第一步：配置路径

1. **ADB 工具路径**
    - 点击「选择目录」按钮，选择你安装的 ADB 工具所在目录（如 `D:\tools\QtScrcpy-win-x86-v3.3.1`）
    - 确保该目录包含 `adb.exe` 文件

2. **QtScrcpy 投屏程序**
    - 点击「选择文件」按钮，选择 `QtScrcpy.exe` 的完整路径
    - 示例：`D:\tools\QtScrcpy-win-x86-v3.3.1\QtScrcpy.exe`

3. **设备 IP 地址**
    - 输入目标 Android 设备的 IP 地址（需开启 USB 调试和网络投屏）
    - 示例：`192.168.1.100`
    - 点击「保存IP」按钮保存当前地址

---

### 第二步：连接与投屏

| 按钮 | 作用 |
|------|------|
| 🔵 **连接设备** | 使用 ADB 连接指定 IP 的设备（执行 `adb connect 192.168.1.100`） |
| 🟦 **启动投屏** | 调用 QtScrcpy 启动投屏窗口，显示设备屏幕 |
| 🟨 **清空设备** | 执行 `adb shell rm -rf /data/data/*`（模拟重置）⚠️ 注意：会删除应用数据 |
| 🟪 **查看日志** | 显示最近的操作记录 |

> ✅ 成功连接后，“就绪”状态会变为绿色。

---

## ⚠️ 注意事项

1. **确保已开启 USB 调试**
    - 在 Android 设备上进入「开发者选项」→ 开启「USB 调试」

2. **启用网络投屏**
    - 在 QtScrcpy 中勾选「允许通过 Wi-Fi 连接」
    - 或手动执行：
      ```bash
      adb tcpip 5555
      adb connect 192.168.1.100:5555
      ```

3. **防火墙设置**
    - 确保电脑防火墙允许 `adb.exe` 和 `QtScrcpy.exe` 访问网络

4. **权限问题**
    - 若提示“拒绝访问”，请以管理员身份运行本程序

5. **清空设备功能风险**
    - 「清空设备」会删除所有应用数据，请谨慎使用！

## 📂 日志说明

程序会在底部显示最近的操作日志，例如：

```
[2025-04-05 14:30:22] 成功连接设备：192.168.1.100
[2025-04-05 14:31:10] 启动 QtScrcpy 投屏...
[2025-04-05 14:32:05] 清空设备数据完成
```

> 日志可用于排查连接失败等问题。

3. 双击 `ADB设备管理器.exe` 运行
