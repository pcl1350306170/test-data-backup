
# 🎬 屏幕录制转GIF工具

> 一个轻量级、图形化的屏幕录制工具，支持自定义区域录制、热键控制、自动保存为GIF格式，适用于快速制作演示动画或分享屏幕内容。

---

## 🧩 功能简介

本工具是一个基于 Python + Tkinter 的桌面应用，提供以下核心功能：

- ✅ **自定义录制区域**：通过鼠标拖拽选择任意屏幕区域进行录制
- ✅ **高亮选区显示**：框选完成后在原位置显示红色边框，便于确认录制范围
- ✅ **热键控制录制**：支持自定义热键（默认 `Ctrl+Shift+Alt+J`）快速开始/停止录制
- ✅ **实时预览窗口**：录制过程中显示当前画面预览
- ✅ **GIF格式输出**：自动将录制内容保存为GIF动图
- ✅ **压缩与循环设置**：支持GIF压缩比例和循环次数配置
- ✅ **自动复制到剪贴板**：录制完成后自动将GIF复制到剪贴板，可直接粘贴使用
- ✅ **自动打开保存目录**：录制完成后自动打开文件所在文件夹

适用于开发者、设计师、教师或需要快速制作屏幕演示的用户。

## 🚀 使用方法

### 第一步：启动程序

1. 双击 `screen_cut_gif.exe` 运行程序
2. 程序界面将显示控制面板，包含：
    - **选择录制区域**：用于框选屏幕区域
    - **开始录制** / **停止录制**：控制录制状态
    - **暂停**：暂停/继续录制
    - **设置**：配置保存目录、热键等参数

---

### 第二步：选择录制区域

1. 点击 **“选择录制区域”** 按钮
2. 屏幕将出现半透明灰色背景
3. 按住鼠标左键拖拽，选择需要录制的区域
4. 松开鼠标后，**红色边框将高亮显示选中区域**（持续10秒）
5. 界面显示当前选区坐标和尺寸信息

> ✅ 确认区域无误后，点击 **“开始录制”** 按钮。

---

### 第三步：开始录制

| 按钮 | 功能 |
|------|------|
| 🔵 **开始录制** | 开始录制选定区域，同时显示悬浮预览窗口 |
| 🟨 **暂停** | 暂停/继续录制 |
| 🔴 **停止录制** | 停止录制并开始处理GIF |

> 💡 **热键控制**：按下默认热键 `Ctrl+Shift+Alt+J` 可快速开始/停止录制。

---

### 第四步：录制完成

1. 录制结束后，程序会自动：
    - 询问保存文件名（默认格式：`recording_YYYYMMDD_HHMMSS.gif`）
    - 应用压缩比例（默认 0.8，可在设置中调整）
    - 保存 GIF 文件到指定目录
    - 将 GIF 复制到剪贴板（可直接粘贴到聊天工具或文档）
    - 自动打开保存目录（如启用此功能）

---

## ⚙️ 设置说明

点击 **“设置”** 按钮可配置以下参数：

| 设置项 | 说明 |
|--------|------|
| **保存目录** | GIF 文件的默认保存位置（支持自定义） |
| **录制热键** | 开始/停止录制的快捷键（默认 `Ctrl+Shift+Alt+J`） |
| **GIF循环次数** | 0 表示无限循环，其他数字表示循环次数 |
| **压缩比例** | 0.1~1.0 之间，1.0 表示不压缩（数值越小文件越小） |
| **自动打开保存目录** | 录制完成后是否自动打开文件所在文件夹 |

---

## ⚠️ 注意事项

1. **屏幕权限**
    - 确保系统允许程序访问屏幕内容（Windows 10/11 可能在隐私设置中开启）

2. **录制性能**
    - 录制区域越大、帧率越高，占用内存越多
    - 建议录制小区域或适当降低压缩比例以减小文件大小

3. **热键冲突**
    - 确保设置的热键不与其他程序冲突
    - 如热键失效，可尝试重启程序或重新设置

4. **GIF文件大小**
    - 长时间录制会产生大文件，建议录制前预估时长
    - 可通过“压缩比例”设置控制文件大小

5. **剪贴板兼容性**
    - 自动复制到剪贴板功能仅支持 Windows 系统
    - 部分软件可能不支持直接粘贴 GIF

## 📂 配置文件说明

程序会在 `json/` 目录下生成 `config_screen_cut_gif.json` 文件，保存以下信息：

```json
{
  "save_dir": "C:\\Users\\YourName\\Desktop",
  "hotkey": "ctrl+shift+alt+j",
  "gif_loop": 0,
  "quality": 0.8,
  "auto_open_dir": true
}
```

> 💡 首次运行时会自动创建配置文件，后续启动会加载上次设置。
