
# 以下是使用**腾讯云开发静态托管**部署代码的详细流程，适用于静态网站（如HTML、CSS、JavaScript、Vue/React打包后的静态文件等）：


### **前提准备**
1. 注册并登录 [腾讯云账号](https://cloud.tencent.com/)（需完成实名认证，个人开发者可正常使用免费额度）。
2. 本地准备好待部署的静态代码（如已打包的前端项目，确保根目录有 `index.html` 作为入口文件）。


### **部署流程**

#### **步骤1：创建云开发环境**
1. 进入 [腾讯云开发控制台](https://console.cloud.tencent.com/tcb)，点击左侧菜单 **“环境”**，再点击 **“新建环境”**。
2. 配置环境信息：
    - **环境名称**：自定义（如 `my-static-host`），仅支持字母、数字、下划线。
    - **环境ID**：自动生成，无需修改。
    - **套餐选择**：个人开发者选 **“免费版”**（满足基础需求，包含5GB存储、每月5GB流量等），点击 **“确认开通”**。
3. 等待环境创建（约1-3分钟），创建完成后进入环境详情页。


#### **步骤2：开通静态托管服务**
1. 在环境详情页左侧菜单，找到 **“静态网站托管”**，点击进入。
2. 首次使用需开通服务，点击 **“立即开通”**，确认服务协议后等待初始化（约10秒）。
3. 开通后会生成默认域名（格式：`环境ID.tcloudbaseapp.com`），后续可绑定自定义域名（需备案）。


#### **步骤3：上传代码文件**
有两种上传方式，根据需求选择：

##### **方式1：控制台手动上传（适合少量文件或测试）**
1. 在“静态网站托管”页面，点击 **“上传文件”** 或 **“上传文件夹”**。
2. 选择本地静态代码的根目录（如 `dist`、`build` 文件夹，包含 `index.html` 及相关资源），等待上传完成（大文件可能需要几分钟）。
3. 上传后文件会显示在文件列表中，确保 `index.html` 在根目录（避免路径错误导致访问异常）。

##### **方式2：命令行工具（CLI）上传（适合开发流程集成）**
1. 安装腾讯云开发CLI：  
   打开终端，执行命令（需先安装Node.js，推荐v12+）：
   ```bash
   npm install -g @cloudbase/cli
   ```
2. 登录云开发账号：  
   终端执行 `tcb login`，会自动打开浏览器，扫码登录腾讯云账号，授权后返回终端。
3. 关联环境：  
   进入本地代码根目录，执行：
   ```bash
   tcb init
   ```  
   按提示选择已创建的环境（如 `my-static-host`），完成初始化（会生成 `cloudbaserc.json` 配置文件）。
4. 上传代码：  
   执行以下命令上传当前目录所有文件到静态托管：
   ```bash
   tcb hosting deploy
   ```  
   如需指定文件夹（如 `dist`），则执行：
   ```bash
   tcb hosting deploy ./dist -e 环境ID  # 环境ID在控制台环境详情页可查
   ```


#### **步骤4：访问部署后的网站**
1. 上传完成后，在“静态网站托管”页面点击 **“默认域名”**（或复制域名），直接在浏览器访问。
2. 若显示正常页面，说明部署成功；若提示“404”，检查 `index.html` 是否在根目录，或文件路径是否正确。


#### **步骤5：更新代码（后续维护）**
- 手动更新：删除旧文件，重新上传新文件（控制台直接替换即可）。
- CLI更新：修改代码后，再次执行 `tcb hosting deploy` 即可覆盖更新。


#### **可选：绑定自定义域名（需备案）**
1. 在“静态网站托管”页面，点击 **“自定义域名”** → **“添加域名”**。
2. 输入已备案的域名（如 `www.example.com`），按提示完成DNS解析配置（在域名服务商处添加CNAME记录，指向控制台提供的目标域名）。
3. 配置SSL证书（腾讯云提供免费证书，或上传自有证书），开启HTTPS，完成后即可通过自定义域名访问。


### **注意事项**
1. 免费版有额度限制（存储、流量、请求数），超出后需升级套餐，避免服务中断。
2. 静态托管仅支持静态文件，若需后端逻辑（如API接口），可结合云开发的“云函数”功能实现。
3. 部署前确保代码中引用的资源路径正确（建议使用相对路径，避免绝对路径导致的跨域或404问题）。

按照以上步骤，即可快速完成静态网站在腾讯云开发的部署，适合个人博客、项目展示页、前端Demo等场景。

# 在 Windows 10 系统中，已安装 `tcb` 命令行工具的情况下，通过腾讯云“静态网站托管”上传本地文件的步骤如下，全程在 **CMD 或 PowerShell** 中操作即可：


### **前提确认**
1. 已安装 `tcb`：打开 CMD/PowerShell，输入 `tcb -v`，能显示版本号即安装成功（若提示“命令不存在”，重新执行 `npm install -g @cloudbase/cli` 安装）。
2. 本地文件准备：确保待上传的静态文件（如 HTML、CSS、JS 等）已整理好，根目录建议包含 `index.html`（作为网站入口）。


### **详细步骤**

#### **1. 登录腾讯云账号**
- 打开 CMD 或 PowerShell（按下 `Win + R`，输入 `cmd` 或 `powershell` 回车）。
- 输入命令并回车：
  ```bash
  tcb login
  ```
- 会自动打开浏览器，扫码登录你的腾讯云账号（需与云开发环境所属账号一致），登录后点击“授权”，关闭浏览器回到终端，显示“登录成功”即可。


#### **2. 进入本地文件目录**
- 假设你的静态文件放在 `D:\my-website` 文件夹（根据实际路径修改），在终端中切换到该目录：
  ```bash
  # 切换到 D 盘（如果文件在其他盘，先输入盘符+冒号，如 D:）
  D:
  # 进入文件夹（路径替换为你的实际文件目录）
  cd D:\my-website
  ```
  提示：输入 `cd ` 后，可直接拖拽文件夹到终端，自动填充路径，避免手动输入错误。


#### **3. 关联云开发环境**
- 若首次在该项目目录操作，需关联已创建的云开发环境（环境需提前在 [腾讯云开发控制台](https://console.cloud.tencent.com/tcb) 创建，且已开通“静态网站托管”）：  
  输入命令并回车：
  ```bash
  tcb init
  ```
- 按提示操作：
    - 选择“关联已有环境”，回车。
    - 从列表中选择你要部署的环境（上下键移动，回车确认）。
    - 后续提示“是否初始化云函数/数据库”等，直接按 `n` 跳过（仅部署静态文件无需这些）。  
      完成后，目录下会生成 `cloudbaserc.json` 配置文件，代表关联成功。


#### **4. 上传本地文件到静态托管**
- 若要上传当前目录下的 **所有文件**（包括子文件夹），输入命令：
  ```bash
  tcb hosting deploy
  ```
- 若只想上传指定文件夹（如打包后的 `dist` 文件夹），输入：
  ```bash
  tcb hosting deploy ./dist  # ./dist 替换为你的目标文件夹路径
  ```
- 终端会显示上传进度，结束后提示“部署成功”，并显示文件数量和耗时。


#### **5. 验证上传结果**
- 登录 [腾讯云开发控制台](https://console.cloud.tencent.com/tcb)，进入你的环境 → 左侧“静态网站托管” → “文件管理”，即可看到上传的文件。
- 点击页面中的“默认域名”，在浏览器中访问，若能正常显示网页，说明上传成功。


### **常见问题解决**
1. **上传后404？**  
   检查 `index.html` 是否在根目录（而非子文件夹），静态托管默认以根目录的 `index.html` 为首页。

2. **文件上传不全？**  
   确保本地文件没有被占用（如被编辑器锁定），可尝试删除 `cloudbaserc.json` 后重新执行 `tcb init` 和 `tcb hosting deploy`。

3. **提示“无权限”？**  
   重新执行 `tcb login` 刷新登录状态，确保账号拥有该云开发环境的管理权限。

按以上步骤操作，即可快速将本地静态文件通过 `tcb` 上传到腾讯云静态托管，适合批量文件或频繁更新的场景。

在腾讯云开发静态托管中，通过 `tcb` 命令行工具删除已上传的文件或文件夹，使用以下命令：


#  **删除指定文件**
```bash
tcb hosting delete 文件名  # 文件名需包含路径（相对于静态托管根目录）
```
示例：删除根目录下的 `test.html` 文件
```bash
tcb hosting delete test.html
```


### **删除指定文件夹（含内部所有文件）**
```bash
tcb hosting delete 文件夹名/  # 文件夹名后加斜杠“/”，表示删除整个文件夹
```
示例：删除根目录下的 `images` 文件夹（及里面所有图片）
```bash
tcb hosting delete images/
```


### **注意事项**
1. 执行命令前，需确保已通过 `tcb login` 登录，并在本地项目目录中（已关联云开发环境，即存在 `cloudbaserc.json` 文件）。
2. 若文件/文件夹在子目录中，需指定完整路径，例如：删除 `static/css/style.css`
   ```bash
   tcb hosting delete static/css/style.css
   ```
3. 操作不可逆，删除后需重新上传才能恢复，请谨慎执行。

执行后终端会提示“删除成功”，可在腾讯云开发控制台的“静态网站托管 → 文件管理”中确认是否已删除。
