# WindowScreen 页面加载逻辑分析

## 整体结构概览

这个 [window_screen.vue](file://C:\www\yh\A纯代码\template【纯代码】\src\views\scenes\window_screen.vue) 文件是一个窗口屏幕页面，主要用于医疗场景中的叫号、候诊等功能展示。

## 详细加载流程分析

### 1. 页面初始化阶段

- **组件引入**：导入表单渲染器、SDK工具、观察者模式工具等
- **Props定义**：接收表单配置、模板信息、API类型等参数
- **数据初始化**：创建大量业务数据对象，包括：
    - [roomScreenData](file:///C:/www/yh/A%E7%BA%AF%E4%BB%A3%E7%A0%81/template%E3%80%90%E7%BA%AF%E4%BB%A3%E7%A0%81%E3%80%91/src/views/scenes/window_screen.vue#L65-L126) - 诊室屏相关数据
    - [msgWinData](file:///C:/www/yh/A%E7%89%B9%E4%BB%A3%E7%A0%81/template%E3%80%90%E7%BA%AF%E4%BB%A3%E7%A0%81%E3%80%91/src/views/scenes/window_screen.vue#L140-L157) - 弹窗配置数据
    - [pauseLayerInfo](file:///C:/www/yh/A%E7%89%B9%E4%BB%A3%E7%A0%81/template%E3%80%90%E7%BA%AF%E4%BB%A3%E7%A0%81%E3%80%91/src/views/scenes/window_screen.vue#L167-L175) - 暂停接诊信息

### 2. 生命周期执行流程

#### mounted 阶段
- 执行 [setRem()](file:///C:/www/yh/A%E7%89%B9%E4%BB%A3%E7%A0%81/template%E3%80%90%E7%BA%AF%E4%BB%A3%E7%A0%81%E3%80%91/src/views/scenes/window_screen.vue#L375-L384) 方法进行屏幕适配（支持2K/4K分辨率）
- 调用 [init()](file:///C:/www/yh/A%E7%89%B9%E4%BB%A3%E7%A0%81/template%E3%80%90%E7%BA%AF%E4%BB%A3%E7%A0%81%E3%80%91/src/views/scenes/window_screen.vue#L205-L229) 方法开始初始化

#### init() 方法执行步骤
1. **SDK服务注册**：
    - 将 [sdkServices](file:///C:/www/yh/A%E7%89%B9%E4%BB%A3%E7%A0%81/template%E3%80%90%E7%BA%AF%E4%BB%A3%E7%A0%81%E3%80%91/src/views/scenes/window_screen.vue#L177-L203) 和 [sdkBizServices](file:///C:/www/yh/A%E7%89%B9%E4%BB%A3%E7%A0%81/template%E3%80%90%E7%BA%AF%E4%BB%A3%E7%A0%81%E3%80%91/src/views/scenes/window_screen.vue#L205-L229) 挂载到父窗口
    - 发送安卓心跳包确认连接正常

2. **模板数据缓存**：
    - 遍历 [formJson.widgetList](file:///C:/www/yh/A%E7%89%B9%E4%BB%A3%E7%A0%81/template%E3%80%90%E7%BA%AF%E4%BB%A3%E7%A0%81%E3%80%91/src/views/scenes/window_screen.vue#L32-L33) 并按 [categoryType](file:///C:/www/yh/A%E7%89%B9%E4%BB%A3%E7%A0%81/template%E3%80%90%E7%BA%AF%E4%BB%A3%E7%A0%81%E3%80%91/src/views/scenes/window_screen.vue#L32-L33) 分类存储到 [modelMap](file:///C:/www/yh/A%E7%89%B9%E4%BB%A3%E7%A0%81/template%E3%80%90%E7%BA%AF%E4%BB%A3%E7%A0%81%E3%80%91/src/views/scenes/window_screen.vue#L135-L135)

3. **参数设置**：
    - 执行 [setParams()](file:///C:/www/yh/A%E7%89%B9%E4%BB%A3%E7%A0%81/template%E3%80%90%E7%BA%AF%E4%BB%A3%E7%A0%81%E3%80%91/src/views/scenes/window_screen.vue#L231-L271) 方法根据模板配置设置各项参数

4. **事件总线创建**：
    - 创建 [SubjectUtil](file:///C:/www/yh/A%E7%89%B9%E4%BB%A3%E7%A0%81/template%E3%80%90%E7%BA%AF%E4%BB%A3%E7%A0%81%E3%80%91/src/utils/observer/SubjectUtil.js#L1-L19) 实例作为事件总线

5. **设备信息获取**：
    - 调用 [AndroidSDK.getDeviceInfo()](file:///C:/www/yh/A%E7%89%B9%E4%BB%A3%E7%A0%81/template%E3%80%90%E7%BA%AF%E4%BB%A3%E7%A0%81%E3%80%91/src/sdk/AndroidSdkService.js#L1-L98) 获取设备信息

### 3. 设备信息回调处理

当获取到设备信息后，执行 [initAfterGetDeviceInfo()](file:///C:/www/yh/A%E7%89%B9%E4%BB%A3%E7%A0%81/template%E3%80%90%E7%BA%AF%E4%BB%A3%E7%A0%81%E3%80%91/src/views/scenes/window_screen.vue#L273-L321) 方法：

#### 特制消息注册
- 执行 [registerMsg()](file:///C:/www/yh/A%E7%89%B9%E4%BB%A3%E7%A0%81/template%E3%80%90%E7%BA%AF%E4%BB%A3%E7%A0%81%E3%80%91/src/views/scenes/window_screen.vue#L323-L337) 方法绑定终端业务标识

#### 主屏功能初始化
- 查找 [categoryType](file:///C:/www/yh/A%E7%89%B9%E4%BB%A3%E7%A0%81/template%E3%80%90%E7%BA%AF%E4%BB%A3%E7%A0%81%E3%80%91/src/views/scenes/window_screen.vue#L32-L33) 为 "room-window" 的组件配置
- 创建 [WindowCommonObserverBiz](file:///C:/www/yh/A%E7%89%B9%E4%BB%A3%E7%A0%81/template%E3%80%90%E7%BA%AF%E4%BB%A3%E7%A0%81%E3%80%91/src/utils/biz/window/WindowCommonObserverBiz.js#L1-L122) 观察者并添加到事件总线
- 如果配置了 API 接口，则创建 [ApiDataUtil](file:///C:/www/yh/A%E7%89%B9%E4%BB%A3%E7%A0%81/template%E3%80%90%E7%BA%AF%E4%BB%A3%E7%A0%81%E3%80%91/src/utils/biz/common/ApiDataUtil.js#L1-L66) 实例处理接口数据
- 如果启用了过号功能，则创建 [RoomOverObserverBiz](file:///C:/www/yh/A%E7%89%B9%E4%BB%A3%E7%A0%81/template%E3%80%90%E7%BA%AF%E4%BB%A3%E7%A0%81%E3%80%91/src/utils/biz/room/RoomOverObserverBiz.js#L1-L25) 观察者

#### 时间头部初始化
- 如果存在 "header" 组件，则创建 [SetDateObserverBiz](file:///C:/www/yh/A%E7%89%B9%E4%BB%A3%E7%A0%81/template%E3%80%90%E7%BA%AF%E4%BB%A3%E7%A0%81%E3%80%91/src/utils/biz/common/SetDateObserverBiz.js#L1-L17) 观察者

#### 通用过号组件初始化
- 如果存在 "pass-patient-common" 组件，创建对应的 [RoomOverObserverBiz](file:///C:/www/yh/A%E7%89%B9%E4%BB%A3%E7%A0%81/template%E3%80%90%E7%BA%AF%E4%BB%A3%E7%A0%81%E3%80%91/src/utils/biz/room/RoomOverObserverBiz.js#L1-L25) 观察者

#### 多媒体资源获取
- 最后调用 [getVideoMedias()](file:///C:/www/yh/A%E7%89%B9%E4%BB%A3%E7%A0%81/template%E3%80%90%E7%BA%AF%E4%BB%A3%E7%A0%81%E3%80%91/src/views/scenes/window_screen.vue#L347-L357) 获取视频资源

### 4. 页面模板结构

- 使用 [VFormRender](file:///C:/www/yh/A%E7%89%B9%E4%BB%A3%E7%A0%81/template%E3%80%90%E7%BA%AF%E4%BB%A3%E7%A0%81%E3%80%91/src/components/public/form-render/index.vue#L1-L43) 渲染表单内容
- 根据 [layerNameKey](file:///C:/www/yh/A%E7%89%B9%E4%BB%A3%E7%A0%81/template%E3%80%90%E7%BA%AF%E4%BB%A3%E7%A0%81%E3%80%91/src/views/scenes/window_screen.vue#L164-L164) 动态渲染弹窗组件
- 显示暂停接诊信息组件

整个页面采用观察者模式实现各组件间的数据交互，并通过 SDK 与安卓端进行通信。
