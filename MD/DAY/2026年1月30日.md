# 页面加载逻辑分析

## 1. 页面主要功能
这个 `room_screen.vue` 是一个**诊室屏入口页面**，负责加载和管理诊室相关的各种业务组件和交互逻辑。

## 2. 主要依赖类分析

### 2.1 核心组件
- **`VFormRender`**: 表单渲染引擎，用于动态渲染诊室屏的各种组件布局

### 2.2 SDK和服务类
- **[AndroidSDK](file://D:\CODE\Yarward\门诊\template1.5.2\src\services\AndroidSdk.js#L2-L4)**:
    - 提供与安卓原生层的通信能力
    - 支持获取设备信息、播放多媒体、写入日志等功能
    - 实现安卓端与前端的双向通信

### 2.3 业务观察者类
- **[RoomCommonObserverBiz](file://D:\CODE\Yarward\门诊\template1.5.2\src\utils\biz\room\RoomCommonObserverBiz.js#L9-L823)**:
    - 诊室通用业务观察者
    - 处理诊室屏的核心业务逻辑
    - 管理医生、患者、候诊等信息的展示

- **[SetDateObserverBiz](file://D:\CODE\Yarward\门诊\template1.5.2\src\utils\biz\common\SetDateObserverBiz.js#L5-L44)**:
    - 日期时间观察者
    - 负责头部时间显示功能

- **[RoomOverObserverBiz](file://D:\CODE\Yarward\门诊\template1.5.2\src\utils\biz\room\RoomOverObserverBiz.js#L6-L110)**:
    - 过号处理观察者
    - 处理患者过号相关业务逻辑

### 2.4 工具类
- **[SubjectUtil](file://D:\CODE\Yarward\门诊\template1.5.2\src\utils\observer\SubjectUtil.js#L5-L15)**:
    - 发布订阅模式的事件总线
    - 实现组件间的解耦通信

- **[resetLongToStr](file://D:\CODE\Yarward\门诊\template1.5.2\src\utils\biz\common\BizUtils.js#L5-L7)**:
    - 数据类型转换工具
    - 处理长整型数据的字符串转换

## 3. 页面加载流程

### 3.1 初始化阶段 (`mounted`)
```javascript
this.setRem();  // 设置屏幕适配
this.init();    // 执行初始化
```


### 3.2 初始化核心逻辑 ([init](file://D:\CODE\Yarward\门诊\template1.5.2\src\utils\biz\common\ApiDataUtil.js#L76-L121) 方法)

#### A. SDK服务注册
```javascript
parent.window.webSDKServices = this.sdkServices;
parent.window.webSDKBizServices = this.sdkBizServices;
AndroidSDK.androidPong();
```


#### B. 数据结构准备
- 遍历 `formJson.widgetList` 构建 `modelMap`
- 根据组件类型 (`categoryType`) 分类存储

#### C. 参数配置设置 ([setParams](file://D:\CODE\Yarward\门诊\template1.5.2\src\services\ajax.js#L34-L40))
- 读取诊室配置 (`room-DRC` 组件)
- 设置医生排序规则 (`doctorOrder`)
- 配置候诊类型和人数限制
- 设置弹窗配置

#### D. 设备信息获取
- 调用 `AndroidSDK.getDeviceInfo()` 获取设备信息
- 等待回调后执行 `initAfterGetDeviceInfo`

### 3.3 设备信息获取后处理 (`initAfterGetDeviceInfo`)

#### A. 消息注册
- 注册特制业务消息标识
- 绑定终端业务标识

#### B. 观察者模式注册
- **诊室业务观察者**: 处理诊室核心业务
- **时间观察者**: 处理头部时间显示
- **过号观察者**: 处理过号逻辑

#### C. 多媒体资源加载
- 调用 `getVideoMedias()` 获取视频组件位置

## 4. 通信机制

### 4.1 安卓通信接口
- **`sdkServices`**: 处理基础SDK服务调用
- **`sdkBizServices`**: 处理业务相关服务调用

### 4.2 事件总线机制
使用 [SubjectUtil](file://D:\CODE\Yarward\门诊\template1.5.2\src\utils\observer\SubjectUtil.js#L5-L15) 实现发布订阅模式，各观察者组件通过事件总线进行通信。

## 5. 屏幕适配
通过 [setRem2](file://D:\CODE\Yarward\门诊\template1.5.2\src\utils\rem.js#L32-L37) 函数根据分辨率进行屏幕适配，支持 2K/4K 等不同分辨率。

## 6. 弹窗管理
页面集成了弹窗管理机制，可根据配置显示就诊提醒、候诊提醒等不同类型弹窗。

整个页面采用**观察者模式**架构，通过事件总线协调各个业务模块，实现诊室屏的动态展示和交互功能。
