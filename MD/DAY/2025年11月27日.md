## 写一个【批量打包文件为压缩包】的python脚本
* 具体需求如下
* 可视化操作，选取某一个文件夹-保存为配置文件，默认H:\NOVEL\合集\old\HH，打包需要保留子目录结构，比如HH下面的A、B、C文件夹，在压缩包里面也要存在。
* 可以选择打包成的文件类型，默认zip，写入配置
* 可以选择是否加密，默认是，写入配置
* 可以设置加密密码，默认“123456”，写入配置
* 可以设置多少个文件生成一个压缩包，默认1000，写入配置
* 可以设置输入打包文件输出路径，默认“D:\bak”，写入配置
* 使用机械硬盘打包，考虑速度优化
* 配置文件引入方式如下：
    * 绝对路径引入配置文件的代码，确保无论脚本在何处执行，都能准确定位到配置文件
    *  配置在“CONFIG_PATH”的json里面
    * 通用数据库配置：DB_CONFIG_PATH，都是在运行脚本的父级目录的json文件夹，里面的DB_CONFIG.json【脚本用不到本地数据库就不用引入了】
* 可视化操作给我加上合适的操作按钮
* 记录操作日志“PROCESS_LOG_FILE”


### 配置实例
```python
# 配置与常量
import os
from pathlib import Path

SCRIPT_DIR = Path(os.path.abspath(os.path.dirname(__file__)))
SCRIPT_NAME = "XXXX_XXXX" #脚本名称
CONFIG_DIR = SCRIPT_DIR / "json"
CONFIG_PATH = CONFIG_DIR / f"config_{SCRIPT_NAME}.json"
CONFIG_DIR.mkdir(exist_ok=True)
DB_CONFIG_PATH = (SCRIPT_DIR.parent) / "json" / "DB_CONFIG.json"
PROCESS_LOG_FILE = SCRIPT_DIR / "json" / "logs" / f"log_{SCRIPT_NAME}.log"
```
