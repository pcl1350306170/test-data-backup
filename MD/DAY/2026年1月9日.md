# MachineScreen 组件分析

## 组件加载逻辑

### 1. 组件注册方式
- **动态导入组件**: 通过导入 `LayerComps` 和 `CommonMachineComps` 对象的属性来批量注册子组件
```javascript
components: {
  VFormRender,
  ...LayerComps,      // 展开层组件
  ...CommonMachineComps, // 通用机器组件
},
```


### 2. 主要子组件
- `VFormRender`: 表单渲染核心组件
- `report-result`: 报到结果展示
- `report-patient`: 报到患者信息
- `report-doctor`: 复诊医生选择
- `report-select-business`: 业务选择
- 以及其他通用弹窗组件

## 数据传递机制

### 1. Props 传递
- **表单数据**: [formJson](file:///C:/www/yh/%E9%97%A8%E8%AF%8A/template1.5.3/src/views/scenes/machine_screen.vue#L13-L18), [formData](file:///C:/www/yh/%E9%97%A8%E8%AF%8A/template1.5.3/src/views/scenes/machine_screen.vue#L20-L20), [optionData](file:///C:/www/yh/%E9%97%A8%E8%AF%8A/template1.5.3/src/views/scenes/machine_screen.vue#L22-L22)
- **API配置**: [parentApi](file:///C:/www/yh/%E9%97%A8%E8%AF%8A/template1.5.3/src/views/scenes/machine_screen.vue#L16-L16)
- **弹窗控制**: 通过 [info](file:///C:/www/yh/%E9%97%A8%E8%AF%8A/template1.5.3/src/views/scenes/machine_screen.vue#L28-L28) 和 [visible](file:///C:/www/yh/%E9%97%A8%E8%AF%8A/template1.5.3/src/views/scenes/machine_screen.vue#L27-L27) 属性控制各弹窗组件的显示和内容

### 2. 事件通信
- **@handle-cancel**: 关闭弹窗事件
- **@handle-sure**: 确认操作事件
- **@close**: 通用关闭事件

## 方法调用机制

### 1. 父子组件方法调用
通过 [parentApi](file:///C:/www/yh/%E9%97%A8%E8%AF%8A/template1.5.3/src/views/scenes/machine_screen.vue#L16-L16) 对象实现父组件方法向子组件的传递：

```javascript
executeParentMethod(key, data) {
  switch (key) {
    case "reportAll":     // 一键报到
    case "toReport":      // 单个报到
    case "handleReport":  // 扫码查询
    // ... 其他方法
  }
}
```


### 2. 子组件调用父组件方法
- 通过 [VFormRender](file:///C:/www/yh/%E9%97%A8%E8%AF%8A/template1.5.3/src/components/public/form-render/index.vue#L1-L1) 组件的 [executeChildMethod](file:///C:/www/yh/%E9%97%A8%E8%AF%8A/template1.5.3/src/components/public/form-render/index.vue#L117-L125) 方法直接调用子组件方法
- 例如: [setDeviceInfo](file:///C:/www/yh/%E9%97%A8%E8%AF%8A/template1.5.3/src/views/scenes/machine_screen.vue#L584-L592), [setDateInfo](file:///C:/www/yh/%E9%97%A8%E8%AF%8A/template1.5.3/src/views/scenes/machine_screen.vue#L594-L602)

### 3. 业务逻辑处理
- **观察者模式**: 通过 [SubjectUtil](file:///C:/www/yh/%E9%97%A8%E8%AF%8A/template1.5.3/src/utils/observer/SubjectUtil.js#L1-L1) 实现事件总线
- **业务观察者**: 如 [MachineObserverBiz](file:///C:/www/yh/%E9%97%A8%E8%AF%8A/template1.5.3/src/utils/biz/machine/MachineObserverBiz.js#L1-L1), [NumberMachineObserverBiz](file:///C:/www/yh/%E9%97%A8%E8%AF%8A/template1.5.3/src/utils/biz/number/NumberMachineObserverBiz.js#L1-L1) 等

## 组件生命周期

### 1. 初始化流程
1. **init()**: 初始化设备信息获取、参数设置
2. **initAfterGetDeviceInfo()**: 获取设备信息后初始化业务观察者
3. **createParentOptions()**: 创建父组件方法传递对象

### 2. 事件处理
- **Android SDK 通信**: 通过 [sdkServices](file:///C:/www/yh/%E9%97%A8%E8%AF%8A/template1.5.3/src/views/scenes/machine_screen.vue#L64-L102) 和 [sdkBizServices](file:///C:/www/yh/%E9%97%A8%E8%AF%8A/template1.5.3/src/views/scenes/machine_screen.vue#L105-L124) 处理原生调用

## 核心设计模式

### 1. 观察者模式
- [eventBus](file:///C:/www/yh/%E9%97%A8%E8%AF%8A/template1.5.3/src/views/scenes/machine_screen.vue#L185-L185) 作为事件总线
- 业务观察者 ([mainEventBus](file:///C:/www/yh/%E9%97%A8%E8%AF%8A/template1.5.3/src/views/scenes/machine_screen.vue#L227-L227)) 处理具体业务逻辑

### 2. 工厂模式
- [createMachineInstance](file:///C:/www/yh/%E9%97%A8%E8%AF%8A/template1.5.3/src/utils/biz/machine/MachineAutoRegistryClass.js#L1-L1) 根据配置创建不同的业务实例

### 3. 单例模式
- [SubjectUtil](file:///C:/www/yh/%E9%97%A8%E8%AF%8A/template1.5.3/src/utils/observer/SubjectUtil.js#L1-L1) 作为全局事件管理器

这个组件采用了一种分层架构，通过表单渲染器作为基础，结合观察者模式处理业务逻辑，实现了灵活的组件通信和方法调用机制。
