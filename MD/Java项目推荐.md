### 📌 如何选择 &利用这些项目

* 如果你 **想提升基础功底**：推荐 JavaGuide、java-design-patterns、JGraphT，这些结构清晰、可读性好。
* 如果你 **想了解企业级/微服务开发**：Spring Boot + Spring Cloud Alibaba + JeecgBoot + Quarkus 是很好的组合。
* 如果你 **想深入工具库 &系统库**：Guava、JobRunr 是非常有价值的参考。
* 看项目时，优先查看：**最近提交时间**、**活跃 issue/PR**、**贡献指南**。参与贡献也能提升自己。
