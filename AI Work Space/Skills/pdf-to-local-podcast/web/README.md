# 🎙️ 本地播客制作系统

基于本地 CosyVoice 模型的 AI 播客制作 Web 系统。提供播客脚本管理、音色管理、任务执行（实时进度）、音频合并+BGM、在线播放等完整功能。

---

## 功能概览

| 模块 | 功能 |
|------|------|
| 📄 脚本管理 | 目录扫描 / 上传 / 内嵌编辑器 / 预解析（字数、块数、预估时长） |
| 🎤 音色管理 | 扫描 TTS 目录自动识别类型 / 一键注册 / 手动注册 / 动态增删 |
| ⚡ 任务控制 | 选择脚本一键生成 / SSE 实时进度条 / 暂停 / 继续 / 停止 / 失败块重试 |
| 🎵 成品管理 | 内嵌播放器在线播放 / 下载 / 清理中间产物（wav） |
| ⚙️ 设置 | 脚本目录 / 输出目录 / 中间产物目录 / TTS 目录 / CosyVoice 环境路径 |

## 使用流程

### 1. 准备播客脚本

播客脚本为 `.md` 格式，必须遵循以下格式规范：

```markdown
【播客信息】
书名：数学历险记
目标时长：30分钟
---
# 注释行，解析器跳过
# 段标题格式：【第N段 标题】

【第1段 开场】
[郭靖] 小朋友们好，欢迎收听《数学历险记》！我是主播郭靖。
[豆包桃子] 我是桃子姐姐。今天我们要去数字王国探险。
[萌萌] 出发！出发！
[雪花] 等等我呀！
```

**格式要点：**

- 头部信息（`---` 之前）：书名、目标时长等元信息
- `---` 分隔行：头部与台词之间必须有
- 段标题：`【第N段 标题】`，仅作结构提示，不生成音频
- 台词行：`[音色名] 台词内容`，音色名必须在已注册音色表中
- 连续同角色台词自动合并为一个块
- 每块建议 30–120 字

### 2. 脚本管理（📄 脚本 Tab）

| 操作 | 说明 |
|------|------|
| 列表 | 自动扫描配置目录下的 `.md` 文件 |
| 选择 | 点击列表项，右侧编辑器加载内容 |
| 新建 | 点击"+ 新建"，输入文件名，自动生成模板 |
| 上传 | 点击"📤 上传"，选择本地 `.md` 文件 |
| 编辑 | 直接在编辑器中修改，无自动保存 |
| 预解析 | 点击"📊 预解析"，查看块数、字数、预估时长、使用的音色 |
| 发送 | 点击"🚀 发送到任务"，跳转到任务 Tab 并预选该脚本 |

### 3. 音色管理（🎤 音色 Tab）

默认 4 个音色（首次启动自动导入）：

| 音色名 | 类型 | 说明 |
|--------|------|------|
| 郭靖 | 男声 | 短视频男声 |
| 豆包桃子 | 女声 | 清亮女声 |
| 萌萌 | 男童 | 儿童男孩声音 |
| 雪花 | 女童 | 儿童女孩声音 |

**注册新音色：**

1. 点击"🔍 扫描 TTS 目录"，列出未注册的音频文件
2. 点击目标音频旁的"注册"按钮，输入音色名称即可
3. 或点击"+ 手动注册"，填写名称、选择音频、类型、prompt_text

**音色参数说明：**

- **参考音频**：用于 CosyVoice zero-shot 音色复刻的音频文件
- **prompt_text**：参考音频的原文转写，默认值为"清晨的风轻轻吹过山头..."
- **声音类型**：男声/女声/男童/女童/童声/未知（扫描时从文件名自动推断）

### 4. 任务执行（⚡ 任务 Tab）

**步骤：**

1. 选择脚本（下拉选择或从脚本 Tab 发送过来）
2. 填写输出文件名（留空自动取脚本书名）
3. 可选：选择 BGM 文件 + 调整音量滑块
4. 可选：展开"高级参数"调整响度（LUFS）和块间静音（ms）
5. 点击"▶ 开始生成"

**任务控制：**

| 按钮 | 说明 |
|------|------|
| ▶ 开始生成 | 启动任务，解析脚本 → 逐块生成 → 合并 |
| ⏸ 暂停 | 当前块生成完后暂停后续块（单块 1-5 分钟不可中断） |
| ▶ 继续 | 从暂停位置恢复生成 |
| ⏹ 停止 | 终止任务，已生成的块保留在磁盘 |
| 🔄 重试失败块 | 仅重新生成失败的块，然后重新合并 |

**进度显示：**

- 总进度条 + 百分比 + 已完成/总数 + 预估剩余时间
- 当前块信息（音色 + 台词预览）
- 块状态网格：⏳待生成 / 🔄生成中 / ✅完成 / ⏭️跳过（已存在） / ❌失败

**断点续转：** 已存在的 wav 文件自动跳过（标记为 ⏭️），中断后重启任务无需重生成已完成的块。

### 5. 成品管理（🎵 成品 Tab）

- 列出输出目录下所有 `.mp3` 成品
- 内嵌 `<audio>` 播放器，直接在线播放
- "💾 下载"按钮下载成品
- "🧹 清理中间产物"清理 `audio` 目录下的 wav 文件（释放磁盘空间）

### 6. 设置（⚙️ 设置 Tab）

| 配置项 | 默认值 |
|--------|--------|
| 脚本扫描目录 | `D:\FILES\糖蛋蛋(＾Ｕ＾)ノ~ＹＯ\播客脚本` |
| 成品输出目录 | `D:\FILES\糖蛋蛋(＾Ｕ＾)ノ~ＹＯ\本地播客` |
| 中间产物目录 | `D:\FILES\糖蛋蛋(＾Ｕ＾)ノ~ＹＯ\audio` |
| TTS 参考音频目录 | `D:\CODE\Python\test-data-backup\AI Work Space\TTS` |
| 目标响度 | -16 LUFS（播客标准） |
| 块间静音 | 400ms |

CosyVoice 环境路径一般不需修改（折叠在"高级参数"中）。修改后点击"💾 保存配置"。

## 时长估算

基于本地 CosyVoice 实测（2026-10-12《清平乐·村居》）：

| 目标时长 | 脚本字数 | 预估块数 |
|----------|----------|----------|
| 10 分钟 | ~2700 字 | ~45 块 |
| 20 分钟 | ~5500 字 | ~90 块 |
| 30 分钟 | ~8100-8300 字 | ~130-145 块 |

**估算公式**：成品秒数 ≈ 字数 × 0.212 + 块数 × 0.4

## 常见问题

**Q: 生成很慢怎么办？**
A: 单块生成需 1-5 分钟（GPU），30 分钟播客约 130+ 块，总耗时较长。支持断点续转，可分多次完成。

**Q: 某块一直失败？**
A: 检查对应音色的参考音频是否存在；文本是否过长（建议 ≤120 字/块）；显存是否充足。失败后可点"重试失败块"单独重试。

**Q: 成品时长和预估差很多？**
A: 预估值基于实测平均语速，实际因文本内容（数字、停顿等）会有偏差。偏差超 ±10% 时系统会提醒。

**Q: 怎么添加新音色？**
A: 把参考音频放到 TTS 目录 → 音色 Tab 点"扫描 TTS 目录" → 点"注册" → 输入名称即可。
