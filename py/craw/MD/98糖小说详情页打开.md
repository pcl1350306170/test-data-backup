* 使用python写一个关于【测试网页埋点数据】的脚本
* 具体需求如下
* 可视化操作，保存为“pyw”
* 读取数据表general_data里面的数据
```sql
 SELECT id, data_key, data_content, data_type
        FROM general_data
        WHERE data_type LIKE '需要埋点的网页-%'
          AND is_deleted=0
```
* 表字段data_content保存的是一个网页链接，脚本需要使用默认浏览器打开这个网页，5s后自动关闭这个网页
* 可以配置几秒关闭刚才打开的网页，默认5s
* 可以配置一次打开几个网页，默认3
* 关闭网页时，需要记录操作日志，需修改数据库is_deleted字段改为1
* 配置文件引入方式如下：
    * 绝对路径引入配置文件的代码，确保无论脚本在何处执行，都能准确定位到配置文件
    * 配置在“CONFIG_PATH”的json里面
    * 通用数据库配置：DB_CONFIG_PATH，都是在运行脚本的父级目录的json文件夹，里面的DB_CONFIG.json
* 可视化操作给我加上合适的操作按钮
* 记录操作日志“PROCESS_LOG_FILE”

```python
# 配置与常量
import os
from pathlib import Path

SCRIPT_DIR = Path(os.path.abspath(os.path.dirname(__file__)))
SCRIPT_NAME = "XXXX_XXXX" #脚本名称
CONFIG_DIR = SCRIPT_DIR / "json"
CONFIG_PATH = CONFIG_DIR / f"config_{SCRIPT_NAME}"
CONFIG_DIR.mkdir(exist_ok=True)
DB_CONFIG_PATH = (SCRIPT_DIR.parent) / "json" / "DB_CONFIG"
PROCESS_LOG_FILE = SCRIPT_DIR / "json" / "logs" / f"log_{SCRIPT_NAME}.log"
```

DB_CONFIG_PATH数据如下：

  "host": "localhost",
