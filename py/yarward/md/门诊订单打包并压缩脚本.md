* 使用python写一个关于【基于某个压缩包，进行打包并压缩】的脚本
* 具体需求如下
* 可视化操作，pyw，可以显示日志
* 选取项目目录，默认【C:\www\yh\门诊\template1.5.0】，写入配置。
* 选择输出目录，默认【D:\yarward\svn\2025-1987南昌市立医院新院区\前端】
* 确认node版本，14+，提醒即可
* 输入订单信息，例如【2025-1987南昌市立医院新院区】其中“2025-1987”是编号，“南昌市立医院新院区”是医院信息，写入配置
* 选择项目版本，选项有【1.5.0、1.5.1、1.5.2、1.5.3】，可以手动输入，写入配置
* 删除项目目录里面的文件夹【lib-render-dist、dist】。
* 选择基础压缩包，默认【C:\www\test\门诊\801S-订单\前端\1.5.1.zip】，写入配置。压缩包里面一定有2个目录【design、resource】
* 开始在项目目录里面打包，依次执行命令“npm run build”“npm run lib-render2”，打包出来的目录分别是“dist”“lib-render-dist”
* 打包完成后，解压【1.5.1.zip】，【1.5.1\design】里面的内容删除，把【design】目录里面的内容复制过去
* 【1.5.1\resource\js\render-design】里面的内容删除，把【lib-render-dist】目录里面的内容复制过去
* 注意，压缩包里面【resource】【resource\js】下还有其他文件，一定不要动，也不用改变目录的层级结构！只把特定目录下的内容替换为打包后的内容
* 替换完成后，重新打包zip，并把压缩包命名为【YM-801S-TLSS-V1.5.1.251987.01001-NCSLYYXYQ-FE】，规则是：YM-801S-TLSS-V(版本号).(订单年份后两位)(订单编号).01001-(医院名称拼音首字母大写)-FE
* zip保存到输出目录，如果存在重名则直接替换
* 打包后zip解压处理，第一层目录需要是【design、resource】
* 配置文件引入方式如下：
    * 绝对路径引入配置文件的代码，确保无论脚本在何处执行，都能准确定位到配置文件
    * 配置在“CONFIG_PATH”的json里面
* 记录操作日志“PROCESS_LOG_FILE”

CONFIG_DIR = SCRIPT_DIR / "json"
CONFIG_PATH = CONFIG_DIR / f"config_{SCRIPT_NAME}.json"
CONFIG_DIR.mkdir(exist_ok=True)
DB_CONFIG_PATH = (SCRIPT_DIR.parent) / "json" / "DB_CONFIG.json"
PROCESS_LOG_FILE = SCRIPT_DIR / "json" / "logs" / f"log_{SCRIPT_NAME}.log"
