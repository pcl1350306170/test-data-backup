## 🚀 快速开始

### 1. 安装依赖

**方式 A：使用安装脚本（推荐）**
```bash
cd py/image
install_dependencies.bat
```

**方式 B：手动安装**
```bash
pip install realesrgan gfpgan basicsr facexlib opencv-python
```

### 2. 运行程序
```bash
python image_enhancer.pyw
```

### 3. 使用步骤
1. 选择图片目录
2. 选择导出目录
3. 设置放大倍数（2/3/4）
4. 勾选"启用人脸增强"（人物照片推荐）
5. 点击"开始增强"

## 🎯 使用建议

### 人物照片（推荐配置）
- 放大倍数：2x 或 4x
- 人脸增强：✅ 启用
- 线程数：根据 GPU 显存（1-2）

### 风景/建筑
- 放大倍数：2x/3x/4x
- 人脸增强：❌ 禁用
- 线程数：根据 GPU 显存

### 批量处理 100+ 张
- 放大倍数：2x（速度优先）
- 线程数：1-2（稳定优先）
- 预计时间：5-10 分钟

## 📝 常见问题

### Q: 模型下载失败？
**A**: 手动下载模型放到 `weights/` 目录：
- RealESRGAN_x4plus.pth (64MB)
- GFPGANv1.4.pth (332MB)

### Q: 显存不足？
**A**: 
1. 减少线程数（设为1）
2. 降低放大倍数（4x → 2x）
3. 关闭人脸增强

### Q: CPU 模式太慢？
**A**: 
- 建议使用 GPU 加速
- 或减少处理图片数量
- 或使用传统插值方法
