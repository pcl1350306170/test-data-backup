# 图片放大增强工具 - 使用说明

## 功能特性

专为**人物照片**优化的图片放大增强工具，采用业界最佳方案：

### 核心技术
- **Real-ESRGAN**：通用图像超分辨率（基于生成对抗网络）
- **GFPGAN**：人脸专用增强（针对人物照片优化）

### 主要功能
✅ 支持 2x/3x/4x 放大  
✅ 人脸专用增强（可选）  
✅ 批量处理支持  
✅ 多线程并行（1-4线程）  
✅ 配置持久化  
✅ 完整的日志记录  
✅ 停止功能（立即响应）

## 使用方法

### 1. 启动程序
```bash
python image_enhancer.pyw
```

### 2. 基本流程
1. 选择图片所在目录
2. 选择导出目录
3. 设置放大倍数（2/3/4）
4. 勾选"启用人脸增强"（处理人物照片时推荐）
5. 点击"开始增强"

### 3. 参数说明

#### 放大倍数
- **2x**：适合轻微放大，速度快
- **3x**：平衡质量和速度
- **4x**：最大放大，细节最清晰，但最慢

#### 人脸增强
- ✅ **启用**：针对人脸区域进行专门优化，五官更清晰立体
- ❌ **禁用**：仅使用 Real-ESRGAN 通用增强

**建议**：
- 人物照片 → 启用
- 风景/建筑 → 禁用
- 混合内容 → 启用（会自动检测人脸）

#### 线程数
- **1线程**：最稳定，推荐 GPU 显存较小（<6GB）时使用
- **2-4线程**：速度快，但显存占用高
- **建议**：根据 GPU 显存调整
  - 4GB：1线程
  - 6-8GB：2线程
  - 12GB+：3-4线程

## 模型文件

程序会自动下载以下模型到 `weights/` 目录：

| 模型 | 文件大小 | 用途 |
|------|----------|------|
| RealESRGAN_x4plus.pth | ~64MB | 通用超分辨率 |
| GFPGANv1.4.pth | ~332MB | 人脸增强 |

**手动下载**（如果自动下载失败）：
- Real-ESRGAN: https://github.com/xinntao/Real-ESRGAN/releases
- GFPGAN: https://github.com/TencentARC/GFPGAN/releases

下载后放到脚本同级的 `weights/` 目录即可。

## 常见问题

### Q1: 模型下载失败怎么办？
**A**: 手动下载模型文件，放到 `weights/` 目录：
```bash
# 创建目录
mkdir weights

# 下载模型
# RealESRGAN_x4plus.pth
# GFPGANv1.4.pth
```

### Q2: 显存不足（OOM）怎么办？
**A**: 
1. 减少线程数（设为1）
2. 降低放大倍数（2x 而非 4x）
3. 处理更小的图片
4. 关闭人脸增强

### Q3: CPU 模式太慢怎么办？
**A**: 
- 建议使用 GPU 加速
- 或者使用传统插值方法（PIL 的 Lanczos）
- 或者减少处理图片数量

### Q4: 处理后的图片有伪影怎么办？
**A**: 
- 降低放大倍数（4x → 2x）
- 关闭人脸增强（如果处理非人物照片）
- 检查原图是否过于模糊（AI 无法完美恢复）

### Q5: 支持哪些图片格式？
**A**: 
- 输入：jpg, jpeg, png, bmp, webp
- 输出：保持原格式，文件名添加 `_enhanced` 后缀

## 高级配置

### 调整显存使用
编辑 `image_enhancer.pyw`，修改 `init_models()` 方法：

```python
self.upsampler = RealESRGANer(
    scale=4,
    model_path='weights/RealESRGAN_x4plus.pth',
    model=model,
    tile=256,      # 改为 256 或 512（分块处理，减少显存）
    tile_pad=10,
    pre_pad=0,
    half=True      # 改为 True（半精度，减少显存，需要 GPU 支持）
)
```

### 自定义模型路径
```python
self.upsampler = RealESRGANer(
    scale=4,
    model_path='your/custom/model.pth',  # 自定义模型路径
    ...
)
```

## 技术原理

### Real-ESRGAN
- **架构**：RRDB（Residual-in-Residual Dense Block）
- **训练数据**：真实世界退化图像（非合成）
- **能力**：恢复纹理、边缘、细节
- **优势**：对真实照片效果极佳

### GFPGAN
- **架构**：基于面部先验的 GAN
- **训练数据**：高质量人脸数据集
- **能力**：恢复五官细节、皮肤质感
- **优势**：人脸修复效果业界领先

### 工作流程
```
1. 读取图片
2. Real-ESRGAN 超分辨率放大
3. GFPGAN 检测人脸区域
4. 对人脸区域进行专门增强
5. 将增强后的人脸融合回原图
6. 保存结果
```
