# 批量图片裁剪工具 - 智能主体检测说明

## 核心改进

### 1. 自动比例模式（推荐）
选择"自动"时，工具会：
- 检测图片中的主体（人物）
- 计算主体的实际宽高比
- 在主体周围添加 15% 的边距缓冲
- 使用主体的自然比例作为裁剪比例
- **确保主体完整包含在裁剪结果中**

### 2. 固定比例智能适配
选择 1:1、16:9 或 9:16 时：
- 如果主体能放入固定比例框 → 正常裁剪，主体居中
- 如果主体太大无法放入 → **自动扩大裁剪框**以包含完整主体
- 始终保持目标比例，但尺寸会自适应

### 3. 主体检测技术
优先级：
1. **rembg**（最佳）- 基于 AI 的背景移除，精准识别主体轮廓
2. **opencv**（次之）- 人脸检测 + 扩展区域估算
3. **中心裁剪**（回退）- 无检测库时默认居中裁剪

## 使用示例

### 场景 1：站立人物照片（高 > 宽）
- **自动模式**：自动识别为竖版比例（如 3:4），完整包含从头到脚
- **1:1 模式**：如果人物太高，会自动扩大裁剪区域以包含完整人物

### 场景 2：多人合影
- 检测最大的人脸区域
- 自动扩展包含所有检测到的主体
- 添加边距避免裁切太紧

### 场景 3：风景照（无人物）
- 自动回退到中心裁剪
- 使用选定的固定比例

## 配置参数

```json
{
  "input_dir": "图片源目录",
  "output_dir": "导出目录",
  "crop_ratio": "自动|1:1|16:9|9:16",
  "thread_count": 5,
  "subject_aware": true
}
```

配置文件位置：`py/image/json/config_batch_image_cropper.json`

## 依赖安装

```bash
# 必需
pip install Pillow

# 可选（强烈推荐）
pip install rembg          # 最佳主体检测
pip install opencv-python  # 人脸检测备选
```

## 注意事项

1. **rembg 首次运行**会下载 AI 模型（约 170MB），后续使用无需重复下载
2. **多线程处理**默认 5 线程，可根据 CPU 性能调整（1-20）
3. **边距缓冲**固定为 15%，确保裁切不会太紧
4. **自动模式**下每张图片的比例可能不同，日志会显示实际使用的比例
