# 🎯 交互式时间轴编辑器使用指南

## 📋 功能介绍

交互式时间轴编辑器让你可以**边听音频边点击图片**，自动记录每张图片的展示时长，无需手动计算和编辑JSON文件！

---

## 🚀 快速开始

### **第1步：安装依赖**

```bash
pip install pygame
```

> **注意：** 交互式编辑器需要 `pygame` 库来播放音频。如果未安装，点击按钮时会提示安装。

---

### **第2步：准备素材**

1. 选择包含图片的文件夹（支持 JPG、PNG、BMP 等格式）
2. 选择音频文件（支持 MP3、WAV、M4A、FLAC 等格式）

---

### **第3步：打开交互式编辑器**

在主界面中，找到"时间轴"设置区域，点击 **"🎯 交互式编辑"** 按钮。

---

### **详细步骤**

#### **1. 开始播放音频**
- 点击 **"▶️ 播放"** 按钮
- 或使用快捷键 **空格键**

#### **2. 监听并标记**
当听到**第1页内容结束**时：
- 立即点击 **P001** 图片
- 系统自动记录：`P001 从 0.0s 开始`

当听到**第2页内容结束**时：
- 立即点击 **P002** 图片
- 系统自动计算：`P001 时长 = 8.5s, P002 从 8.5s 开始`

依此类推...

#### **3. 实时预览**
右侧"时间轴预览"区域会实时显示：
- ✅ 已标记的图片（绿色）
- ⏳ 等待标记的图片（灰色）
- 每页的开始时间、结束时间、持续时长

#### **4. 完成所有标记**
当所有图片都标记完成后，会弹出提示：
```
✅ 已标记所有 100 张图片！

请点击'保存时间轴'生成 JSON 文件
```

#### **5. 保存时间轴**
- 点击 **"💾 保存时间轴"** 按钮
- 选择保存位置（默认在音频文件同目录）
- 自动生成 `timeline.json` 文件

#### **6. 返回主界面生成视频**
- 关闭窗口，回到主界面
- 时间轴文件路径已自动填入
- 点击 **"🎬 开始生成视频"**

## 🛠️ 常用操作

### **撤销标记**
如果点错了图片：
- 点击 **"↩️ 撤销"** 按钮
- 或使用快捷键 **Ctrl+Z**

### **重置所有标记**
如果想重新开始：
- 点击 **"🔄 重置"** 按钮
- 确认后会清除所有标记

### **暂停调整**
如果需要暂停思考：
- 点击 **"⏸ 暂停"** 按钮
- 或再次点击 **"▶️ 播放"** 继续

## 💡 实用技巧

### **技巧1：提前练习**
第一次使用时，可以先不标记，完整听一遍音频，熟悉节奏。

### **技巧2：保持专注**
标记过程需要集中注意力，建议在安静环境中进行。

### **技巧3：分批标记**
如果图片很多（如100张），可以：
1. 先标记前20张
2. 保存时间轴
3. 重新打开编辑器，继续标记剩余图片

> **注意：** 目前版本不支持断点续标，建议一次性完成。

### **技巧4：检查时间轴**
保存前，仔细检查"时间轴预览"区域：
- 是否有异常长的页面（>30秒）
- 是否有异常短的页面（<2秒）
- 总时长是否接近音频时长

### **技巧5：微调时长**
如果某页标记不准确：
1. 撤销到该页之前
2. 重新播放并标记

## ❓ 常见问题

### **Q1: 点击播放没有声音？**
**A:** 检查以下几点：
1. 系统音量是否开启
2. 音频文件是否正常（用播放器测试）
3. pygame 是否正确安装：`pip install pygame`

### **Q2: 图片缩略图显示不出来？**
**A:** 需要安装 Pillow 库：
```bash
pip install Pillow
```

### **Q3: 不小心点错了顺序怎么办？**
**A:** 
- 如果只是错了一张：点击"↩️ 撤销"
- 如果错了很多：点击"🔄 重置"重新开始

### **Q4: 可以不按顺序点击吗？**
**A:** 不可以。系统强制要求按顺序点击（从左到右、从上到下），这是为了确保时间轴的正确性。

### **Q5: 最后一张图片怎么确定结束时间？**
**A:** 有两种方式：
1. **自动计算**：标记完最后一页后，系统会自动使用"音频总时长 - 最后开始时间"作为最后一页时长
2. **手动结束**：听到音频结束时点击最后一页，然后立即点击"保存"

### **Q6: 可以中途保存吗？**
**A:** 可以！即使没有标记完所有图片，也可以点击"💾 保存时间轴"。未标记的图片会自动分配平均时长。

### **Q7: 保存的JSON文件可以手动编辑吗？**
**A:** 当然可以！保存后的JSON文件格式如下：
```json
{
  "0010.png": 8.5,
  "0020.png": 12.3,
  "0030.png": 6.7
}
```
你可以用记事本打开，手动修改数值。

## 🚨 注意事项

1. **按顺序点击**：必须从左到右、从上到下依次点击
2. **及时标记**：听到每页结束时立即点击，不要延迟
3. **保存备份**：建议定期保存，防止意外丢失
4. **检查时长**：保存前务必检查时间轴预览
5. **音频质量**：确保音频清晰，便于判断每页结束点
