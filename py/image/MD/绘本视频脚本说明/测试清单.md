# ✅ 交互式时间轴编辑器 - 测试清单

## 📋 测试前准备

### **1. 安装依赖**

```bash
pip install pygame
```

或使用一键脚本：
```bash
双击运行 "启动工具.bat"
```

### **2. 准备测试素材**

- **图片文件夹**：5-10张测试图片（JPG/PNG）
- **音频文件**：1-2分钟MP3/WAV文件

---

## 🧪 功能测试

### **测试1：启动检查**

- [ ] 双击 `audiobook_video_generator.pyw` 能正常启动
- [ ] 主界面显示正常
- [ ] 日志区域显示 "✅ 配置加载成功"
- [ ] 如果未安装pygame，显示警告信息

**预期结果：**
```
[HH:MM:SS] ✅ 配置加载成功
```

### **测试2：打开交互式编辑器**

**步骤：**
1. 选择图片文件夹
2. 选择音频文件
3. 点击 "🎯 交互式编辑" 按钮

**检查点：**
- [ ] 新窗口打开，标题为 "⏱️ 交互式时间轴编辑器"
- [ ] 图片缩略图正确显示（4列网格）
- [ ] 音频控制按钮可用
- [ ] 进度条显示 00:00.0 / XX:XX.X
- [ ] 时间轴预览区域显示操作说明

**预期界面：**
```
┌─────────────────────────────────┐
│ 🔊 音频控制                      │
│ [▶️ 播放] [⏹ 停止] ...          │
│ 当前时间: 00:00.0 / 01:30.0     │
├─────────────────────────────────┤
│ 📸 点击图片标记时间戳             │
│ [P001] [P002] [P003] [P004]    │
│ [P005] [P006] [P007] [P008]    │

```

### **测试3：音频播放**

**步骤：**
1. 点击 "▶️ 播放" 按钮

**检查点：**
- [ ] 音频开始播放
- [ ] 按钮文字变为 "⏸ 暂停"
- [ ] 进度条实时更新
- [ ] 时间显示递增（00:00.1, 00:00.2, ...）
- [ ] 日志显示 "▶️ 开始播放音频"

**快捷键测试：**
- [ ] 按空格键能暂停/继续播放

### **测试4：标记时间戳**

**步骤：**
1. 播放音频
2. 听到第1页结束时，点击 P001 图片

**检查点：**
- [ ] P001 图片边框变绿
- [ ] P001 下方文字变为绿色，显示时长
- [ ] 时间轴预览更新，显示第1页信息
- [ ] 日志显示 "✅ 标记第 1 页: P001.png @ X.Xs"

**预期时间轴预览：**
```
  1. P001.png |    0.0s -  ???  | 等待下一页... ⏳

已标记: 1/8 页
```

---

### **测试5：连续标记**

**步骤：**
1. 继续播放
2. 听到第2页结束时，点击 P002 图片
3. 听到第3页结束时，点击 P003 图片

**检查点：**
- [ ] 每张图片都能正确标记
- [ ] P001 的时长自动计算（第2页开始时间 - 第1页开始时间）
- [ ] 时间轴预览实时显示所有已标记页面
- [ ] 统计信息更新（已标记: 3/8 页）

**预期时间轴预览：**
```
  1. P001.png |    0.0s -   5.3s |   5.3s ✅
  2. P002.png |    5.3s -  12.8s |   7.5s ✅

```

### **测试7：撤销功能**

**步骤：**
1. 标记3张图片
2. 点击 "↩️ 撤销" 按钮
   或按 Ctrl+Z

**检查点：**
- [ ] 最后标记的图片恢复为未标记状态（灰色）
- [ ] 时间轴预览移除该条目
- [ ] 统计信息更新（已标记: 2/8 页）
- [ ] 日志显示 "↩️ 撤销第 3 页的标记"

---

### **测试8：重置功能**

**步骤：**
1. 标记多张图片
2. 点击 "🔄 重置" 按钮
3. 确认对话框中选择 "是"

**检查点：**
- [ ] 所有图片恢复为未标记状态
- [ ] 时间轴预览清空
- [ ] 统计信息显示 "已标记: 0/8 页"
- [ ] 日志显示 "🔄 已重置所有标记"

---

### **测试9：保存时间轴**

**步骤：**
1. 标记所有图片
2. 点击 "💾 保存时间轴" 按钮
3. 选择保存位置
4. 点击 "保存"

**检查点：**
- [ ] 生成 JSON 文件
- [ ] 文件格式正确（见下方示例）
- [ ] 主界面时间轴路径自动填充
- [ ] 日志显示 "💾 时间轴已保存: timeline.json"
- [ ] 弹出成功提示对话框

**预期JSON格式：**
```json
{
  "P001.png": 5.3,
  "P002.png": 7.5,
  "P003.png": 6.2,
  "P004.png": 8.1,
  ...
}
```
