## 🚀 使用流程

### **步骤1：安装依赖**

双击运行 `启动工具.bat`，自动检查并安装所有依赖。

或手动安装：
```bash
pip install pygame
```

### **步骤2：启动工具**

```bash
python audiobook_video_generator.pyw
```

或双击 `audiobook_video_generator.pyw`

### **步骤3：选择素材**

1. 选择图片文件夹
2. 选择音频文件

### **步骤4：打开编辑器**

点击 **"🎯 交互式编辑"** 按钮

### **步骤5：边听边标记**

1. 点击 **"▶️ 播放"**
2. 听到第1页结束时，点击 **P001** 图片
3. 听到第2页结束时，点击 **P002** 图片
4. 依此类推...

### **步骤6：保存时间轴**

点击 **"💾 保存时间轴"**，生成 `timeline.json`

### **步骤7：生成视频**

返回主界面，点击 **"🎬 开始生成视频"**

## 💡 技术亮点

### **1. 双版本兼容**

同时支持 moviepy 1.x 和 2.x：
```python
try:
    from moviepy import AudioFileClip  # 2.x
except ImportError:
    from moviepy.editor import AudioFileClip  # 1.x
```

### **2. 线程安全**

使用 `root.after()` 确保UI更新在主线程执行：
```python
self.root.after(0, lambda: self._log(msg))
```

### **3. 资源管理**

自动清理临时文件和pygame资源：
```python
def _close(self):
    if HAS_PYGAME:
        pygame.mixer.music.stop()
        pygame.mixer.quit()
    self.window.destroy()
```

### **4. 智能容错**

- 图片加载失败不影响其他图片
- 音频裁剪失败自动降级使用原音频
- pygame缺失时提供友好提示

## 📝 已知限制

### **当前版本限制**

1. **必须按顺序点击**
   - 原因：确保时间轴正确性
   - 未来计划：支持任意顺序，后期排序

2. **不支持断点续标**
   - 原因：实现复杂度较高
   - 未来计划：保存中间状态

3. **单音轨支持**
   - 原因：简化实现
   - 未来计划：支持多音轨切换

4. **无波形图显示**
   - 原因：需要额外库支持
   - 未来计划：集成 librosa 或 pydub
