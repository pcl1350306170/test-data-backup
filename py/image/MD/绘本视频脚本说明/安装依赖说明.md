# 📦 交互式时间轴编辑器 - 安装指南

## 🔧 必需依赖

### **1. python-vlc（音频播放）**

```bash
pip install python-vlc
```

**作用：** 用于播放音频文件并获取实时播放进度

**重要提示：** 还需要安装 VLC 播放器软件！
- 下载地址：https://www.videolan.org/vlc/
- 选择 Windows 版本下载安装

**验证安装：**
```bash
python -c "import vlc; print('✅ python-vlc 已安装')"
```

预期输出：
```
✅ python-vlc 已安装
```

---

### **2. Pillow（图片缩略图）**

```bash
pip install Pillow
```

**作用：** 用于生成图片缩略图，在编辑器中显示

**验证安装：**
```bash
python -c "from PIL import Image; print('Pillow 已安装')"
```

预期输出：
```
Pillow 已安装
```

> **注意：** 你的系统中已经安装了 Pillow ✅

---

### **3. moviepy（视频生成）**

```bash
pip install moviepy
```

**作用：** 用于合成图片和音频生成视频

**验证安装：**
```bash
python -c "import moviepy; print('moviepy 版本:', moviepy.__version__)"
```

预期输出：
```
moviepy 版本: 2.2.1
```

> **注意：** 你的系统中已经安装了 moviepy 2.2.1 ✅

---

## 🚀 一键安装所有依赖

```bash
pip install python-vlc Pillow moviepy
```

**注意：** 还需要手动安装 VLC 播放器软件！

## ⚠️ 常见问题

### **Q1: pip 命令找不到？**
**A:** 确保 Python 已添加到系统 PATH，或使用完整路径：
```bash
C:\Users\你的用户名\AppData\Local\Programs\Python\Python3x\Scripts\pip.exe install pygame
```

### **Q2: 安装失败，提示网络错误？**
**A:** 使用国内镜像源加速：
```bash
pip install pygame -i https://pypi.tuna.tsinghua.edu.cn/simple
```

### **Q3: python-vlc 安装后导入失败？**
**A:** 确保已安装 VLC 播放器软件：
1. 访问 https://www.videolan.org/vlc/
2. 下载并安装 Windows 版本
3. 重启电脑后再试

### **Q4: 多个 Python 环境？**
**A:** 确保在正确的环境中安装：
```bash
# 查看当前 Python 路径
where python

# 在该 Python 环境中安装
python -m pip install pygame
```

## ✅ 安装完成检查

运行以下命令检查所有依赖：

```bash
python -c "
try:
    import pygame
    print('✅ pygame:', pygame.ver)
except ImportError:
    print('❌ pygame: 未安装')

try:
    from PIL import Image
    print('✅ Pillow: 已安装')
except ImportError:
    print('❌ Pillow: 未安装')

try:
    import moviepy
    print('✅ moviepy:', moviepy.__version__)
except ImportError:
    print('❌ moviepy: 未安装')
"
```

预期输出：
```
✅ python-vlc: 已安装
✅ Pillow: 已安装
✅ moviepy: 2.2.1
```

## 🎯 开始使用

安装完成后，运行主脚本：

```bash
python audiobook_video_generator.pyw
```

或者双击 `audiobook_video_generator.pyw` 文件。

在主界面中：
1. 选择图片文件夹
2. 选择音频文件
3. 点击 **"🎯 交互式编辑"** 按钮
4. 开始边听边标记！
