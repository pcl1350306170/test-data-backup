# ⚡ 音频倍速播放功能说明

## 🎯 功能概述

交互式时间轴编辑器新增了**音频倍速播放**功能，让你可以加快或减慢音频播放速度，从而更高效地标记时间轴！

---

## 🚀 使用方法

### **1. 找到倍速控制**

在交互式编辑器的"🔊 音频控制"区域，你会看到：

```
播放倍速: [1.0 ▼] x  (加快标记速度)
```

### **2. 选择倍速**

点击下拉框，可选的倍速包括：

| 倍速 | 说明 | 适用场景 |
|------|------|---------|
| **0.5x** | 半速播放 | 需要精确标记时 |
| **0.75x** | 稍慢播放 | 仔细聆听细节 |
| **1.0x** | 正常速度 | 默认设置 |
| **1.25x** | 稍快播放 | 熟悉内容后加速 |
| **1.5x** | 快速播放 | 加快标记进度 ⚡ |
| **2.0x** | 双倍速 | 快速浏览 🚀 |

### **3. 实时切换**

- 可以在**播放过程中**随时切换倍速
- 新速度会**立即生效**
- 日志会显示速度变化：`⚡ 播放速度: 1.0x → 1.5x`

## ⚙️ 技术实现

### **VLC 倍速 API**

```python
# 设置播放倍速
self.media_player.set_rate(1.5)  # 1.5倍速

# 获取当前倍速
current_rate = self.media_player.get_rate()
```

### **支持的倍速范围**

VLC 理论上支持 **0.1x - 10.0x**，但我们限制了常用范围：
- 最低：0.5x（太慢没有意义）
- 最高：2.0x（太快影响准确性）

## ❓ 常见问题

### **Q1: 倍速播放会影响音高吗？**

**A:** VLC 使用了**时间拉伸算法**，改变速度时**不会改变音高**。
- 1.5x 播放：声音更快，但音调不变
- 0.5x 播放：声音更慢，但音调不变

这与老式磁带机不同（磁带机会改变音高）。

---

### **Q2: 为什么有时候倍速切换没反应？**

**A:** 可能的原因：
1. **VLC 版本过旧**：建议升级到 3.0.20+
2. **音频格式不支持**：某些特殊格式可能不支持倍速
3. **硬件解码限制**：某些硬件加速器可能不支持

**解决方法：**
- 更新 VLC 到最新版本
- 尝试其他倍速值
- 重启程序

---

### **Q3: 倍速会影响标记精度吗？**

**A:** 
- **1.0x - 1.5x**：精度基本不受影响 ✅
- **1.5x - 2.0x**：需要更多练习，精度略降 ⚠️
- **>2.0x**：不建议，精度明显下降 ❌

**建议：**
- 初学者：使用 1.0x - 1.25x
- 有经验：可以使用 1.5x
- 熟练用户：可以尝试 2.0x

---

### **Q4: 可以在播放中途切换倍速吗？**

**A:** 可以！这是本功能的核心优势。

**示例场景：**
```
1. 用 1.5x 快速播放前10页
2. 遇到复杂页面，切换到 0.75x 仔细听
3. 标记完成后，切回 1.5x 继续
```

---

### **Q5: 倍速设置会保存吗？**

**A:** 目前**不会保存**，每次打开编辑器都恢复为 1.0x。

**未来计划：** 可能会添加配置保存功能。
