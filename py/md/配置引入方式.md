绝对路径引入配置文件的代码，确保无论脚本在何处执行，都能准确定位到配置文件：

```python
# 配置与常量
import os
from pathlib import Path

SCRIPT_DIR = Path(os.path.abspath(os.path.dirname(__file__)))
SCRIPT_NAME = "chinese_translator"
CONFIG_DIR = SCRIPT_DIR / "json"
CONFIG_PATH = CONFIG_DIR / f"{SCRIPT_NAME}_config.json"
CONFIG_DIR.mkdir(exist_ok=True)
```

### 关键修改说明：
1. **引入绝对路径基准**：  
   通过 `SCRIPT_DIR = Path(os.path.abspath(os.path.dirname(__file__)))` 获取当前脚本所在目录的绝对路径，作为后续路径拼接的基准。

2. **配置路径绝对化**：
    - `CONFIG_DIR` 变为「脚本所在目录 + json文件夹」的绝对路径
    - `CONFIG_PATH` 变为「脚本所在目录 + json文件夹 + 配置文件名」的绝对路径

3. **兼容性保障**：  
   无论脚本是在当前目录执行、其他目录执行，还是被其他程序调用，都能通过绝对路径找到配置文件，避免因工作目录变化导致的路径错误。

修改后，配置文件会固定保存在 `脚本所在目录/json/chinese_translator_config.json`，且脚本始终能正确读取该路径。
