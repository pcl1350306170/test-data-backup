# 病房 Web 开发辅助工具 - 功能与接口说明

## 概述

本插件通过浮动菜单提供 6 项功能，所有功能均通过 `fetch` 请求外部代理服务，**不调用当前页面所在服务的接口**。

- **外部接口基地址（apiBaseUrl）**：`http://192.168.18.228:28019`（可在插件设置页修改）
- **请求方式**：均为 `POST`，`Content-Type: application/json`

---

## 功能清单与对应接口

### 1. 👤 添加用户

| 项目 | 值 |
|------|-----|
| 接口地址 | `{apiBaseUrl}/yh-mock/create-host-data` |
| sqlType | `insertUser` |
| 请求参数 | `dbHost`、`dbPort`、`dbName`、`username`、`password`、`sqlType`、`directExecution`、`username_emp` |
| 说明 | 向目标数据库添加账号，`dbHost` 默认从当前页面 URL 提取 |

### 2. 🗑️ 删除某 IP 占用的设备

| 项目 | 值 |
|------|-----|
| 接口地址 | `{apiBaseUrl}/yh-mock/create-host-data` |
| sqlType | `deleteip` |
| 请求参数 | `dbHost`、`dbPort`、`dbName`、`username`、`password`、`sqlType`、`directExecution`、`deleteip` |
| 说明 | 删除指定 IP 占用的设备记录 |

### 3. 📂 添加护理标签分类

| 项目 | 值 |
|------|-----|
| 接口地址 | `{apiBaseUrl}/yh-mock/create-host-data` |
| sqlType | `addlabelclass` |
| 请求参数 | `dbHost`、`dbPort`、`dbName`、`username`、`password`、`sqlType`、`directExecution`、`addlabelclassnum` |
| 说明 | 向数据库批量添加护理标签分类 |

### 4. 🏷️ 添加护理标签（每分类）

| 项目 | 值 |
|------|-----|
| 接口地址 | `{apiBaseUrl}/yh-mock/create-host-data` |
| sqlType | `addlabel` |
| 请求参数 | `dbHost`、`dbPort`、`dbName`、`username`、`password`、`sqlType`、`directExecution`、`addlabelnum` |
| 说明 | 每个分类下批量添加护理标签 |

### 5. 📤 上传 localStorage

| 项目 | 值 |
|------|-----|
| 接口地址 | `{apiBaseUrl}/upload-localstorage` |
| 请求参数 | `pageUrl`（当前页面地址）、`pageHost`（当前页面域名）、`data`（localStorage 键值对 JSON） |
| 说明 | 读取当前页面的 localStorage 数据，POST 到外部服务保存 |

### 6. 📦 批量创建设备

| 项目 | 值 |
|------|-----|
| 接口地址 | `{apiBaseUrl}/api/v1/device-proxy/create` |
| 请求参数 | `serverIp`、`port`、`contextPath`、`orgId`、`deptId`、`deviceType`、`apiVersion`、`ip`、`deviceName`、`deviceNum`、`deviceAppId`、`deviceModel`、`mac`、`versions`、`params`、`positions` 等 |
| 说明 | 逐条循环创建，每次间隔 300ms；支持老/新接口切换（`apiVersion`）、多种设备类型 |

#### 辅助接口：获取机构列表

| 项目 | 值 |
|------|-----|
| 接口地址 | `{apiBaseUrl}/api/v1/orgs/getOrgs` |
| 请求参数 | `serverIp` |
| 说明 | 在批量创建设备弹窗中，点击"获取"按钮时调用，用于自动获取并填入 orgId |

### 7. 📋 宣教分类添加（调用当前页面服务接口）

| 项目 | 值 |
|------|-----|
| 接口地址 | `{当前页面origin}/hpms/web-hp/articleCategory` |
| 请求参数 | `id`（空字符串）、`categoryName`（随机生成）、`nurseUnitId`（病区宣教从 localStorage `selectDeptInfo` 取 `deptId`，全院宣教传 `0`）、`title`（固定 "添加"） |
| 说明 | 下拉选择病区/全院宣教，随机生成分类名（默认10条），逐条调用接口保存，每次间隔 200ms |

### 8. 📝 宣教添加（调用当前页面服务接口）

| 项目 | 值 |
|------|-----|
| 查询分类接口 | `GET {当前页面origin}/hpms/web-hp/articleCategory?IsPage=0&nurseUnitId={nurseUnitId}` |
| 保存接口 | `POST {当前页面origin}/hpms/web-hp/edArticle` |
| 保存请求参数 | `title`（随机生成）、`nurseUnitId`（病区取 localStorage deptId / 全院传 0）、`categoryId`（勾选的分类 ID）、`contentText`（固定内容）、`url`（固定图片链接）、`isShowDoor:1`、`articleType:0`、`tags:[]`、`isEnable:1` 等 |
| 说明 | 选择宣教类型后自动加载分类列表，勾选分类（默认全选），设置每个分类添加几条（默认10），逐条调用接口保存 |

### 9. 🖥️ Mock 数据（混合调用）

| 项目 | 值 |
|------|-----|
| 查询设备接口 | `GET {当前页面origin}/tdms/web-td/device/list?deptId={deptId}&deviceType={deviceType}&contain=1&size=100&page=1` |
| 查询患者接口 | `POST {当前页面origin}/bnms/web-bn/patient-list/list` |
| 生成文件接口 | `POST {apiBaseUrl}/yh-mock/create-files`（外部代理，返回 blob 下载） |
| 说明 | 输入 deptId + 选择设备类型（床头/床旁），查询设备和患者数据，按 bedName 匹配后弹窗展示，支持单项/全部生成，生成 mock.zip 下载 |

> **注意**：此功能调用的是**当前页面所在服务的接口**，不经过外部代理服务。通过通用函数 `callPageApi` 实现，后续新功能可复用此函数。

---

## 调用架构

```
Chrome 插件 (content.js)
        │
        │  fetch POST
        ▼
外部代理服务 (192.168.18.228:28019)
        │
        │  代理执行 SQL / 调用业务接口
        ▼
目标数据库 (YHDB) / 病房业务服务
```

插件本身不直接连接数据库或调用目标页面业务接口，所有操作均通过外部代理服务中转。

> 例外：宣教分类添加、宣教添加功能通过 `callPageApi` / `callPageApiGet` 通用函数直接调用当前页面所在服务的接口。
